# Route — Telegram Mini App

Здесь лежит **собранное** приложение, которое отдаётся по адресу
Mini App. Исходники не здесь — этот репозиторий существует только ради
хостинга на GitHub Pages.

Открывать так, как задумано: `t.me/meeroute/app`.

Сейчас приложение работает на демо-данных: 17 московских заведений,
офферы и история лежат в самом бандле, бэкенд не подключён. Это видно в
интерфейсе — сверху висит полоска «демо-режим».
